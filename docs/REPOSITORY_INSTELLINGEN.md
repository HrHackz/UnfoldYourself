## GitHub Pages

- bron: deploy vanaf branch;
- branch: `main`;
- map: `/ (root)`;
- custom domain: leeg tenzij later toegevoegd;

## Beveiliging

- private vulnerability reporting inschakelen;
- secret scanning inschakelen waar beschikbaar;
- push protection inschakelen waar beschikbaar;
- dependency alerts zijn beperkt relevant omdat er geen pakketafhankelijkheden zijn;
- `SECURITY.md` behouden.

## Branchbescherming

Voor `main`:

- pull request vóór samenvoegen verplicht bij samenwerking;
- minstens één review bij externe bijdragers;
- force pushes blokkeren;
- branch deletion blokkeren;
- gesprekken oplossen vóór merge;
- administrator bypass alleen bewust gebruiken.
