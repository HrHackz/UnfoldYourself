# GitHub Wiki-pakket

De Markdownbestanden in deze map zijn klaar om als GitHub Wiki te gebruiken.

Een GitHub Wiki wordt technisch apart van de hoofdrepository opgeslagen. Plaats daarom de inhoud van deze map in de Wiki-interface of clone de wiki-repository en kopieer de bestanden daarnaartoe.

Aanbevolen startvolgorde:

1. `Home.md`
2. `_Sidebar.md`
3. `Gebruik-en-installatie.md`
4. `Testen-en-rapporten.md`
5. `Privacy-en-back-ups.md`
6. `Technische-architectuur.md`
7. `Onderhoud-en-releases.md`
